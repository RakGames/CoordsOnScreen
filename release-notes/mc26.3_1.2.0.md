## CoordsOnScreen — Minecraft 26.3 (mc26.3_1.2.0)

CoordsOnScreen now has a **Minecraft 26.3** build. Same 1.2.0 feature set you already know — this is a compatibility release for the new Minecraft version.

### What's new
- **Built for Minecraft 26.3.** Updated to Fabric Loader 0.19.5, Fabric API 0.161.0+26.3, Cloth Config 26.3.159, and ModMenu 21.0.0.
- **Structure display updated for 26.3.** Minecraft changed its structure lookup API in this version; the mod now uses the new call, so the structure line keeps working exactly as before (singleplayer only).

### Which file do I download?
| Minecraft version | File |
| --- | --- |
| 26.3 | `coordsonscreen-mc26.3_1.2.0.jar` |
| 26.2 | `coordsonscreen-mc26.2_1.2.0.jar` |
| 26.1.2 | `coordsonscreen-mc26.1.2_1.2.0.jar` |

Each build is made for one Minecraft version — just pick the one matching your game.

### Requirements
Requires **Fabric API**. **Cloth Config** and **ModMenu** are optional (used together for the in-game settings screen); without them the mod is fully configurable via `config/coordsonscreen.json`.

*This is a client-side mod. You do not need to install it on servers.*
